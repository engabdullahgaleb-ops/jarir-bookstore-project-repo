#  مكتبة جرير

هذا مشروع Flutter مستوحى من تطبيق **مكتبة جرير**، تم تطويره بهدف التعلم والتدرب على بناء تطبيقات حديثة باستخدام Flutter و Firebase، مع التركيز على تنظيم المشروع، إدارة الحالة، وتصميم واجهات مستخدم قابلة لإعادة الاستخدام.

> **ملاحظة:** هذا المشروع تعليمي، وليس التطبيق الرسمي لمكتبة جرير.

---

##  المميزات

* شاشة البداية (Splash Screen)
* تصميم مخصص للتطبيق
* خط مخصص
* دعم الوضع الفاتح والوضع الداكن
* دعم اللغتين العربية والإنجليزية
* الترجمة باستخدام Flutter l10n
* تسجيل الدخول بواسطة Google باستخدام Firebase
* تسجيل الدخول بالبريد الإلكتروني وكلمة المرور
* إنشاء حساب جديد مع التحقق من صحة البيانات
* تخزين البيانات باستخدام Cloud Firestore
* شريط علوي (AppBar)
* شريط تنقل سفلي (Bottom Navigation)
* استخدام ListView و GridView و PageView
* مؤشرات تنقل سلسة (Smooth Page Indicator)
* انتقالات وحركات بسيطة بين الصفحات
* Bottom Sheets
* إدارة الحالة باستخدام Bloc/Cubit
* مؤشرات تحميل أثناء تنفيذ العمليات
* مكونات قابلة لإعادة الاستخدام

##  التقنيات المستخدمة

##  طريقة التثبيت

### 1. استنسخ المشروع

```bash
git clone https://github.com/engabdullahgaleb-ops/jarir-bookstore-project-repo.git
```

### 2. انتقل إلى مجلد المشروع

```bash
cd jarir-bookstore-project-repo
```

### 3. ثبّت الحزم

```bash
flutter pub get
```

### 4. إعداد Firebase

قم بربط المشروع مع Firebase وأضف ملفات الإعداد الخاصة بمنصتك، مثل:

* `google-services.json` لتطبيق Android.
* `GoogleService-Info.plist` لتطبيق iOS (عند الحاجة).

### 5. تشغيل التطبيق

```bash
flutter run
```
